# Windows and Linux VPS Commercial Page Brief

## Decision

Create two public, indexable commercial pages:

- `/windows-vps/`
- `/linux-vps/`

Keep `/plans.html` as the comparison and checkout hub.

## Shared customer promise

Help customers choose and order a VPS by operating system, workload, region, and resources.

Do not claim faster, cheaper, more reliable, or best performance without verified evidence.

## Page 1: Windows VPS

**Primary intent:** Commercial purchase.

**Primary keywords:** `windows vps`, `cheap windows vps`, `windows vps hosting`, `windows vps buy`.

**Secondary keywords:** `windows vps hosting usa`, `windows vps with remote desktop`, `windows vps europe`.

**Required sections:**

1. Windows VPS definition and customer fit.
2. Windows workloads and Remote Desktop use cases.
3. Plan resources and region selection.
4. What happens after payment.
5. Support and customer responsibilities.
6. Windows VPS FAQs.
7. Plan CTA linking to `/plans.html#windows-vps` and the existing checkout.

## Page 2: Linux VPS

**Primary intent:** Commercial purchase.

**Primary keywords:** `linux vps`, `linux vps hosting`, `cheap linux vps`, `vps linux ubuntu`.

**Secondary keywords:** `buy vps linux`, `cheap ubuntu vps`, `linux vps server`.

**Required sections:**

1. Linux VPS definition and customer fit.
2. Linux, Ubuntu, web hosting, and development use cases.
3. Plan resources and region selection.
4. Root or administrative access wording only if verified.
5. What happens after payment.
6. Support and customer responsibilities.
7. Linux VPS FAQs.
8. Plan CTA linking to `/plans.html#linux-vps` and the existing checkout.

## Shared SEO requirements

- Public and indexable production URLs.
- Preview must be noindex and robots-blocked.
- Unique title, meta description, canonical, and H1.
- Correct H2 and H3 order.
- Self-contained opening answer.
- Unique copy for each page.
- Breadcrumbs and valid structured data.
- Internal links to the hub, comparison, and relevant guides.
- No broken internal links.
- Useful image alt text.
- No placeholder text.
- No unsupported claims, metrics, reviews, or prices.
- Sitemap inclusion after publication.
- Existing shared checkout and OS selector remain unchanged.

## Navigation

Do not add new top-level header items yet.

Add contextual links from:

- Homepage.
- `/plans.html`.
- Footer Products menu.
- Windows versus Linux article.
- RDP performance article.
- VPS resource article.

## Measurement

Track separately for each page:

- Non-brand impressions.
- Organic clicks.
- Signups.
- Checkout starts.
- Paid VPS orders.
- Organic revenue.

## Acceptance criteria

- Both pages have unique content and canonical URLs.
- Both pages target separate operating-system intent.
- Both pages link to the correct hub section.
- Both pages preserve the existing checkout.
- PR checks pass.
- Preview crawler passes.
- Live verification passes after publication.
