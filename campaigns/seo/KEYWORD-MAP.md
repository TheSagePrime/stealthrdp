## Exclusions

Do not target as primary commercial pages:

- Generic `vps`.
- Free VPS terms.
- Provider-brand terms.
- Generic remote-desktop software terms.
- Broad `best vps` terms before independent evidence exists.

## Cannibalisation rules

- `/plans.html` compares both operating systems.
- `/windows-vps/` sells Windows VPS.
- `/linux-vps/` sells Linux VPS.
- Supporting pages answer one use case or question.
- Do not copy the same plan table and paragraphs across pages.
- Every new URL needs one primary intent and one canonical URL.
